# 🧭 Sidebar Menu

A sleek **slide-in sidebar navigation menu** built with pure **HTML & CSS**. A frosted-glass menu glides over a full-screen background, toggled by a hamburger button — no JavaScript required.

![Sidebar Menu preview](Screenshots/sidebar-menu.png)

## ✨ Features

- 🍔 Hamburger button opens the sidebar with a smooth slide animation
- ❌ Close icon hides the menu again
- 🧊 Translucent "glass" panel with a soft glow and shadow
- 🔗 Seven menu items with **Font Awesome** icons
- 🌟 Hover effects on menu items, buttons, and social icons
- 🌐 Social media icons (Facebook, Twitter, Instagram, YouTube)
- 🖼️ Full-screen background image that stays fixed behind the menu

## 🕹️ How to Use

| Action | Control |
| ------ | ------- |
| Open the sidebar | Click the ☰ hamburger icon (top-left) |
| Close the sidebar | Click the ✕ icon in the sidebar |
| Menu links | Placeholder links (`#`) — connect your own pages |

## 🚀 How to Run

No build step or installation needed.

```bash
cd "Sidebar Menu"
# open index.html in your browser
```

Or serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/Sidebar%20Menu/`.

> 🌐 An internet connection is needed for the Google Fonts (Poppins) and Font Awesome CDN assets.
