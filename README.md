# 🌐 Web Development Mini Projects

A growing collection of **mini web projects** — small front-end builds, UI clones, and experiments, each kept in its own folder.

Every project is self-contained: open its `index.html` in a browser, or serve the repo locally and browse to it.

## 📁 Repository Layout

```text
web-development-mini-projects/
├── <project-1>/
│   ├── index.html
│   ├── style.css
│   ├── assets...
│   └── README.md
├── <project-2>/
│   └── ...
└── ...
```

## 🚀 Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/mohit-1025/web-development-mini-projects.git
   cd web-development-mini-projects
   ```

2. **Open a project**

   Open its `index.html` directly in your browser, or serve the repo locally:

   ```bash
   python -m http.server 8000
   ```

   Then visit `http://localhost:8000/` and pick a project folder.

> 🌐 Some projects load fonts, icons, or other assets from CDNs, so an internet connection may be needed.

## 🕹️ Controls

Controls and interactions vary by project — check each project's **README** for details.

## 🧰 Requirements

- 🌍 A modern web browser
- 🐍 Python 3 (optional — only for running a local static server)

Happy browsing and building! 🚀
